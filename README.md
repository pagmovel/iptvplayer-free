# IPTV Player Free

Player de IPTV para celular Android: TV ao vivo com programação, filmes, séries, busca rápida e
favoritos. Entra com servidor, usuário e senha (Xtream Codes) do seu próprio provedor. O app não
inclui nenhum conteúdo nem lista.

> Em construção. O design está em
> [docs/superpowers/specs/2026-11-10-iptv-player-free-design.md](docs/superpowers/specs/2026-11-10-iptv-player-free-design.md).

## Para desenvolvedores

O APK é compilado pelo GitHub Actions. Não precisa de Android SDK na máquina.

Ferramentas do Claude Code usadas no projeto:

- **superpowers**: brainstorming, planos e execução.
- **context-mode**: leitura e execução com saída filtrada.
- **impeccable**: verificação de qualidade visual.
